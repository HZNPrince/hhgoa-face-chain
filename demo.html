Screen Recording Guide

HH Goa Face Chain Demo

Use this page as your speaking guide while recording. The actual project remains a Rust CLI pipeline; this page is only for demo preparation.

One-Line Flow

1. Face scan input 2. Web and social discovery 3. Evidence hash 4. Solana devnet verification

Commands To Show

Run the real demo with the default env-based config:

cargo run -- --image samples/orry.jpg

After the run, open generated proof links:

open data/links.html

What The Output Files Mean

  • data/evidence.json: the exact evidence package that gets hashed.
  • data/report.json: the machine-readable run summary for debugging or review.
  • data/links.html: a clickable proof report generated after the run.

2:15

The hash is written to Solana devnet using a memo transaction. The program then re-verifies the confirmed transaction and checks that the memo contains the same evidence hash.
